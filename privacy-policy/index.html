개인정보처리방침

최종 수정일: 2026년 6월 21일

1. 개요

본 디스코드 봇(이하 "봇")은 서비스 제공을 위해 최소한의 데이터를 처리할 수 있습니다. 본 개인정보처리방침은 어떤 정보를 수집하며, 어떻게 사용하고 보호하는지 설명합니다.

2. 수집하는 정보

봇은 다음과 같은 정보를 수집하거나 처리할 수 있습니다.

  • Discord 사용자 ID
  • Discord 서버 ID
  • 채널 ID
  • 역할(Role) 정보
  • 봇 명령어 사용 기록
  • 서비스 운영에 필요한 설정 데이터
  • 오류 로그 및 진단 정보

3. 정보 수집 목적

  • 봇 기능 제공
  • 명령어 처리
  • 서버 설정 저장
  • 오류 수정 및 서비스 개선
  • 악용 방지 및 보안 유지

4. 데이터 보관 기간

수집된 데이터는 서비스 운영에 필요한 기간 동안만 보관됩니다. 사용자가 데이터 삭제를 요청하거나 서비스 운영이 종료되는 경우 관련 데이터는 합리적인 기간 내에 삭제됩니다.

5. 데이터 공유

개발자는 사용자의 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 다만 법률상 요구가 있거나 법적 의무를 이행해야 하는 경우 예외가 적용될 수 있습니다.

6. 데이터 보호

개발자는 개인정보 보호를 위해 합리적인 보안 조치를 적용하고 있으며, 무단 접근·변조·유출을 방지하기 위해 노력합니다.

7. 사용자 권리

사용자는 자신의 데이터에 대한 열람, 수정 또는 삭제를 요청할 수 있습니다. 요청이 접수되면 합리적인 기간 내에 처리됩니다.

8. Discord와의 관계

본 봇은 Discord 플랫폼에서 운영되는 독립적인 제3자 서비스입니다. Discord의 개인정보 처리에 대해서는 Discord의 개인정보처리방침을 참고하시기 바랍니다.

9. 정책 변경

본 개인정보처리방침은 필요에 따라 변경될 수 있으며, 변경 사항은 본 페이지를 통해 공지됩니다.
